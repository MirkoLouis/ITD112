# ITD112

ITD112 Activity and Project Repository: every laboratory exercise and project for the course, one folder each.

| # | Activity | Stack | Location |
|---|---|---|---|
| Lab 1 | Integrating Soil and Weather APIs | Python, Streamlit, SoilGrids v2.0, Open-Meteo | [`api-app/`](api-app/) |
| Final Project | Visualization of Healthcare System Indicators and Health Outcomes: The Philippines vs East Asia and Pacific, 2000 to 2023 | R (ggplot2, pheatmap), Python (Seaborn, scikit-learn, SHAP), Streamlit, World Bank WDI | [`healthcare-case-study/`](healthcare-case-study/) |

The Final Project is also the ITD105 final requirement; see [MirkoLouis/ITD105](https://github.com/MirkoLouis/ITD105).

Each activity has its own README with setup and run instructions. Shared ignore rules live in the root `.gitignore`. Project-specific ones go in that project's folder.
